# Глубже — тихий подводный промысел

Уютный подводный рыбацкий дайв-симулятор в браузере: встаёшь на пирс, прыгаешь в лагуну с аквалангом, ловишь рыбу руками, сдаёшь улов и прокачиваешь снаряжение, чтобы нырять всё глубже.

Three.js r187 (через jsDelivr CDN, без npm), один `index.html` и модульный JS, весь мир, рыбы, дайвер и звук генерируются процедурно.

## Запуск

ES-модули не грузятся с `file://`, поэтому нужен любой статический сервер:

```bash
python3 -m http.server 8000
# открыть http://localhost:8000
```

Нужен интернет для CDN (Three.js, Google Fonts) и браузер с WebGL 2.

## Управление

| Клавиша | Действие |
| --- | --- |
| `W A S D` + мышь | идти по пирсу / плыть туда, куда смотришь |
| `Пробел` | прыжок с пирса · нырок с поверхности · рывок под водой |
| `ЛКМ` | зажать — потянуться к рыбе, отпустить, когда кольцо в бирюзовой зоне |
| `Shift` | быстрее (под водой тратит больше воздуха) |
| `C` | вниз (под водой) / нырнуть с поверхности |
| `E` | подняться на пирс по лестнице |
| `U` / `Tab` | мастерская (на берегу) |
| `V` · `L` · `M` | вид 1-е/3-е лицо · фонарь · звук |
| `Esc` | пауза и настройки |

На сенсорных экранах появляются джойстик, обзор пальцем и кнопки.

## Игровой цикл

1. Пирс → прыжок (дуга, всплеск, кольца на воде, переход камеры под воду с каплями на маске при выходе).
2. Под водой тратится воздух: базово 60 с, чем глубже — тем быстрее; на поверхности баллон пополняется.
3. Рыба замечает дайвера спереди гораздо лучше, чем сзади, и «слышит» скорость. Подкрадывайся медленно со спины; глаз-индикатор под прицелом показывает, насколько она насторожена.
4. Захват — тайминг: зажми ЛКМ, кольцо сходится, отпусти в бирюзовой зоне. Промах пугает рыбу и её стаю.
5. Пойманная рыба бьётся в руке, потом уходит в сумку. Всплывай, плыви к лестнице (маркер «Пирс»), поднимайся — скупщик считает улов, дайвер поднимает трофей.
6. Ракушки и опыт тратятся в мастерской. Кислород на нуле — не смерть: лодка подбирает тебя у пирса, но улов уплывает.

### Рыбы

| Вид | Редкость | Где | Особенность |
| --- | --- | --- | --- |
| Серебристая сардинка | обычная | отмель | стаи по 12–16, быстрые |
| Коралловый окунь | обычная | отмель, склон | группы у дна и свай |
| Песочный иглобрюх | редкая | у дна | раздувается от испуга и замедляется |
| Лазурный хирург | редкая | коралловый склон | нужен хват 2 |
| Золотая луна-рыба | легендарная | синяя бездна | огромная, светится, нужен хват 3 |

### Улучшения

Баллон (воздух), ласты (скорость и манёвренность), хват (дальность, ширина зоны, сила для крупной рыбы), сумка (вместимость), фонарь (свет на глубине), гидрокостюм (лимит глубины 10 → 20 → 36 м, открывает зоны). Цена растёт с уровнем, часть уровней требует уровень дайвера. Прогресс хранится в `localStorage` (`glubzhe.save.v1`).

## Арт-дирекшн

- **Стиль:** стилизованный low-poly с плоским затенением и ручными градиентами в вершинных цветах. Ни одной текстуры: всё процедурное, в одном языке форм.
- **Палитра** из шести цветов: бирюза `#3CCFC4`, глубокий синий `#0E3D63`, тёплый песок `#F2D7A6`, коралл `#FF6F5E`, пена `#FFF4E3`, солнце `#FFC870`. Остальные тона (дерево, камень, лагуна, бездна) смешаны из них.
- **Свет:** тёплое контровое солнце над морем, полусферический амбиент, тени PCF, каустика на всём, что под водой, поглощение света с глубиной (красный уходит первым), фонарь дайвера.
- **Постобработка:** bloom, DOF с фокусом на дайвере, грейдинг через две 3D-LUT (над водой / под водой), Khronos PBR Neutral тонмаппинг, зерно, виньетка, хроматическая аберрация по краям, волновое искажение под водой, капли на маске.
- **Шрифты:** Clash Display, General Sans, Satoshi и Space Grotesk не содержат кириллицы (проверено по глифам), поэтому взята пара того же характера с кириллицей: **Unbounded** (заголовки, лого), **Onest** (текст), **JetBrains Mono** (цифры HUD).
- **UI:** стеклянные панели, кислород — круговой манометр, глубиномер с лимитом костюма, единый набор штриховых иконок, тосты улова, баннеры зон.

## Устройство

```
index.html        разметка UI, иконки (SVG-спрайт), importmap
css/style.css     стиль интерфейса
js/main.js        загрузка, игровые режимы, цикл кадра, мастерская/сдача/пауза
js/player.js      состояния дайвера, физика, ловля, камера, фонарь, подсказки
js/fish.js        процедурные модели рыб, инстансинг, анимация в шейдере, boids + FSM
js/diver.js       процедурная модель дайвера и смешивание поз
js/world.js       рельеф, пирс, хижина, пальмы, камни, водоросли, кораллы, буйки, свет
js/water.js       поверхность моря: волны, преломление, пена, окно Снеллиуса снизу
js/sky.js         небо, облака, острова, чайки
js/fx.js          пузыри, планктон, брызги, искры, лучи света, луч фонаря
js/post.js        конвейер рендера и финальный грейдинг
js/shaders.js     общие uniform'ы и GLSL: туман, каустика, поглощение, фонарь
js/audio.js       синтезированные эмбиент, музыка и эффекты (WebAudio)
js/ui.js, input.js, save.js, config.js, util.js
```

**Рендер за кадр:** проход сцены без воды в половинном разрешении (цвет + глубина для преломления) → основной MSAA-проход, где вода сэмплирует его для преломления, толщины и пены → bloom → финальный проход.

**Производительность:** все стаи — `InstancedMesh` с анимацией в вершинном шейдере, сетка воды полярная и плотная только у камеры, тени обновляются один раз за кадр, динамическое разрешение снижает нагрузку на слабых GPU и телефонах, а в паузе меняется пресет «Красиво / Быстро».

## Отладка

В консоли доступен `window.__game`: `__game.give(500)` — ракушки, `__game.tp(x, y, z)` — телепорт, `__game.debug.timeScale` — ускорение времени.
